# Seed Legends – Spielprototyp

Grow- und Genetik-Spiel im Comic-/Low-Poly-Stil (18+). Testversion Akt 1.

## Spielen
- `index.html` – Testspiel (Startbildschirm, Akt 1)

Lokal starten:
```
python3 -m http.server 8000
```
Dann `http://localhost:8000/` im Browser öffnen. (Ein Doppelklick auf die HTML-Datei reicht nicht, weil die `.json`-Dateien nachgeladen werden.)

## Dateien
- `seed-legends-pflanzen.json` – 3D-Pflanzen (6 Phasen)
- `seed-legends-outfits.json` – Spielfigur in 7 Outfits
- `seed-legends-welt.json` – Insel, Häuser, Straßen, Auto, Grow Shop

## Steuerung
W/S laufen · A/D drehen · V Ansicht · E Tür/Auto/Gespräch · M Karte

Prototyp – Grafiken und Inhalte vorläufig. Sponsor-Logos nur zur Präsentation.
